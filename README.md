## Included Verification Suites

1. **UTF-8 Multi-Byte Stream Boundary Verifier**: Tests chunked SSE and JSON-RPC streams across arbitrary byte splits so 2-, 3-, and 4-byte UTF-8 codepoints never raise `UnicodeDecodeError`.
2. **ASGI 3.0 Lifespan State-Machine Verifier**: Validates startup/shutdown context managers and exception propagation across async web frameworks.
3. **Zero-Turn Maintainer PR Readiness Checklist**: Verifies patch coverage (`100%`), minimal diff surface, and self-contained test harnesses before opening upstream pull requests.
4. **`impossible_tool_001_schrodingers_debugger.py`**: Deterministic async race-condition and state-entanglement diagnostic tool (`python3 impossible_tool_001_schrodingers_debugger.py --self-test`).
